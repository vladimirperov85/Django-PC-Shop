# Функционал

Возможности интернет-магазина PC_Shop.

## Каталог товаров

- Категории товаров (игровые сборки, офисные и другие)
- Поиск по названию: параметр `?q=` сохранением запроса при пагинации
- Пагинация: 9 товаров на страницу
- Карточки товаров с изображениями (загрузка через админ-панель)

!!! tip "Подсказка"

   Поиск работает в подстроке без учёта регистра —
    запрос «rtx» найдёт и «RTX 4060», и «rtx 3050».

## Корзина покупок

Корзина хранится в сессии пользователя — не требует авторизации
и сохраняется между перезагрузками страницы.

=== "Обычное добавление"

    Классическая форма: добавили товар — перешли в корзину.
    Повторное добавление того же товара блокируется с предупреждением.

=== "AJAX-добавление"

    Товар добавляется без перезагрузки страницы:
    счётчик в шапке обновляется, показывается уведомление.
    Реализовано через `JsonResponse` и JavaScript на стороне клиента.

!!! warning "Ограничение"

    Один товар может лежать в корзине только в одном экземпляре —
   повторное добавление игнорируется.

## Заказы

- Оформление заказа с формой контактов (имя, телефон, email, адрес)
- Автоматическая привязка заказа к авторизованному пользователю
- Жизненный цикл статусов:

   ```text
    Новый → Оплачен → Доставлен
      ↘ Отменён
   ```

- Страница «Мои заказы» — только свои заказы, доступ по `@login_required`
- Имитация оплаты: статус «Новый» меняется на «Оплачен»

## Пользователи

- Регистрация с автоматическим входом после создания аккаунта
- Вход/выход через встроенные классы Django (`LoginView`, `LogoutView`)
- Защита личных данных: заказ виден только его автору

!!! success "Безопасность"

   Доступ к чужим заказам невозможен: выборка в БД идёт
    с условием `user=request.user`, а не только по ID заказа.
