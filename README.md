## ✨ Возможности

- **Каталог товаров** — просмотр всех доступных сборок ПК
- **Фильтрация по категориям** — игровые, офисные и другие сборки
- **Детальные страницы товаров** — полное описание, характеристики, изображение
- **Корзина** — добавление товаров, изменение количества, удаление (на сессиях)
- **Оформление заказа** — форма с данными покупателя, сохранение в БД
- **Аутентификация** — регистрация, вход, выход пользователей
- **Личный кабинет** — история заказов с привязкой к аккаунту
- **Уведомления** — сообщения об успешных действиях (добавление в корзину, оформление заказа)
- **Адаптивный дизайн** — Bootstrap 5, корректное отображение на мобильных устройствах

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd PC_Shop
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

```bash
# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Настройка переменных окружения

Скопируйте шаблон и заполните секретный ключ:

```bash
copy .env.example .env
```

Откройте `.env` и укажите `SECRET_KEY`. Сгенерировать ключ можно так:

```python
from django.core.management.utils import get_random_secret_key
print(get_random_secret_key())
```

### 6. Применение миграций

```bash
python manage.py migrate
```

### 7. Создание суперпользователя (админ)

```bash
python manage.py createsuperuser
```

### 8. Запуск сервера

```bash
python manage.py runserver
```

Откройте в браузере: http://127.0.0.1:8000/

## 🌐 Основные страницы

| Страница | URL | Описание |
|---|---|---|
| Главная | `/` | Список всех товаров |
| Каталог | `/category/<slug>/` | Товары категории |
| Товар | `/product/<slug>/` | Детальная страница товара |
| Корзина | `/cart/` | Содержимое корзины |
| Оформление | `/order/create/` | Форма оформления заказа |
| Подтверждение | `/order/created/` | Страница успешного заказа |
| Вход | `/login/` | Авторизация |
| Регистрация | `/register/` | Создание аккаунта |
| Мои заказы | `/my-orders/` | История заказов |
| Админка | `/admin/` | Панель управления |

## 👨‍💼 Админ-панель

Доступна по адресу `/admin/`.

Возможности:
- Управление категориями товаров
- Управление товарами (добавление, редактирование, цены, наличие)
- Загрузка изображений товаров
- Просмотр и управление заказами
- Изменение статуса оплаты заказов

## 🔐 Переменные окружения

Файл `.env` содержит секретные данные. **Никогда не публикуйте его в Git.**

| Переменная | Описание |
|---|---|
| `SECRET_KEY` | Секретный ключ Django (обязательно) |

Шаблон доступен в файле `.env.example`.

## 🧪 Разработка

### Создание нового приложения

```bash
python manage.py startapp <имя_приложения>
```

Не забудьте добавить приложение в `INSTALLED_APPS` в `settings.py`.

### Миграции

```bash
# Создать миграции после изменения моделей
python manage.py makemigrations

# Применить миграции
python manage.py migrate
```

### Загрузка тестовых данных

Через админ-панель: добавьте категории и товары в разделе `Shop → Products`.
